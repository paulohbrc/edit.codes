Run code carefully

This site runs your single-page HTML in the Output panel — inside your browser. The preview blocks network requests (fetch, XHR, external scripts/images) with a Content-Security-Policy.

  • Social engineering: fake login pages can still trick you visually inside the preview.
  • Malicious JavaScript may still run locally. Sandbox + CSP reduce risk — they do not make every paste safe.
  • Never paste code you do not understand, especially from strangers.
  • Do not enter real passwords, bank data, or private tokens here.
